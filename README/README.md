# Zöldebb mindennapok – Környezetvédelem egyszerűen

**Téma:** Környezetvédelem a mindennapokban  
**Készítők:** Malatinszky Alexandra, Kovács-Simon Eszter  
**Tantárgy:** IKT Projektmunka I. 

## Rövid bemutatás
A projekt azt mutatja be, hogyan kapcsolódik a környezetvédelem a mindennapi döntéseinkhez. Fő témái a hulladékmegelőzés és szelektív gyűjtés, a víz- és energiatakarékosság, a tudatos vásárlás, az élelmiszer-pazarlás csökkentése és a fenntarthatóbb közlekedés.

## Digitális produktumok
- Bootstrap 5 alapú, 5 oldalas projektweboldal
- 13 diás prezentáció
- 18 kérdéses online kérdőív, 20 kitöltővel
- Kérdőíves elemzés és diagramok
- Projektterv és 3–5 oldalas projektbeszámoló

## Használt eszközök
Visual Studio Code, HTML5, CSS3, Bootstrap 5, Google Forms, Microsoft Excel, Microsoft PowerPoint, Microsoft Word, Git és GitHub.

## Eredmények összefoglalása
A kérdőívet 20 fő töltötte ki. 75% rendszeresen szelektíven gyűjti a hulladékot, 85% rendszeresen figyel az energiafogyasztás csökkentésére, 80% mindig leoltja a villanyt, 80% nagyon fontosnak tartja a környezetvédelmet, ugyanakkor 70% leggyakrabban autóval közlekedik. A felmérés nem reprezentatív, de jól szemlélteti a megkérdezett csoport szokásait.
